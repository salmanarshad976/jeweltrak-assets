Install in email

  1. Click Copy HTML Signature.
  2. Open Gmail or Outlook signature settings and create a new signature.
  3. Paste into the signature editor and save.
  4. Send a test email to check layout, images, and links.

Remote images are hosted publicly on GitHub and may require the recipient to allow images in their email client.
