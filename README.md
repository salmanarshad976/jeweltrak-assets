# JewelTrak HTML Email Signature

Hosted HTML email signature for **David Dukes, Owner**.

## Files

- `index.html` — browser-based signature preview and copy installer.
- `signature.html` — standalone email signature layout.
- `images/` — publicly accessible brand assets used by the signature (logo, icons, and footer wave).
- `jeweltrak-signature.html` — earlier version retained for reference.

## Publish with GitHub Pages

1. Open [Repository Settings → Pages](https://github.com/salmanarshad976/jeweltrak-assets/settings/pages).
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Set **Branch: main** and **Folder: /(root)**.
4. Click **Save**.

When GitHub Pages has published the site, the live installer should be:

https://salmanarshad976.github.io/jeweltrak-assets/

The standalone signature will be at:

https://salmanarshad976.github.io/jeweltrak-assets/signature.html

## Install in email

Open the live installer page, select **Copy signature**, and paste into the email signature editor in Gmail or Outlook. Send a test email to check links and image loading. Some email clients may initially suppress remote images.

The images in the HTML signature use `raw.githubusercontent.com` URLs so they remain reachable independently of GitHub Pages configuration.
